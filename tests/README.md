# テスト

ブラウザ（Chromium）でゲームを実際に動かして確かめるテストです。
1つでも失敗すると終了コード1で終わります。

```sh
cd tests
npm install        # はじめの1回だけ
node run.js        # ぜんぶ流す（30秒ほど）
node run.js undo   # ファイル名かケース名に「undo」を含むものだけ
```

Chromium は `CHROME_PATH` → `/opt/pw-browsers` の中 → Playwright まかせ、の順にさがします。
Claude Code on the web の環境なら、そのまま動きます。

| ファイル | 見ているもの |
|---|---|
| `layout.test.js`  | どの画面サイズでも はみ出さない・重ならない |
| `task.test.js`    | おだいの手数・クリア判定・ほめことば・ヒント |
| `clock.test.js`   | とけいの おだい（時こくの計算・はりを あわせる判定・虹・みちしるべ・ドラムロール）と まぜまぜ |
| `undo.test.js`    | もどす（3手まで） |
| `beginner.test.js`| ビギナー（1〜10のキー・記録は別・手数は見ない） |
| `profile.test.js` | ひなた と パパ の記録を混ぜない |
| `settings.test.js`| 歯車の「せってい」（大きさ・クイズ）と「おだい」タブ |
| `smoke.test.js`   | ひととおり動かして止まらない |

## おだいを足すとき

`index.html` の `TASKS` の **いちばん うしろ** に1行足します（記録は番号で持っているので、とちゅうに入れると ずれます）。`best`・`ref`・`way` は仮の値でかまいません。

```sh
node tools/solver.js --write   # best/ref/way を計算しなおして書きかえる
node tools/solver.js --check   # 合っているか確かめる（テストでも見ている）
node tools/solver.js 777 7 10  # 1問だけ手数を見る
```

- `best` … 機械の最短手数（追い越して引く、などの裏技も使う）
- `ref`  … おてほん手数（＋ × ×2 ÷2 だけ）。「じょうず！」は ref＋2手いない
- `way`  … ビギナーの「みちしるべ」（とちゅうで作る数）。おてほんの道から自動で作る。
  自動の道がヒントの考え方とずれるときは、`tools/solver.js` の `WAY_FIX` に手で書く。
  `--check` は、みちしるべの数が その数字だけで作れることも確かめる

### とけいの おだい（まぜまぜ）

とけいの おだいは `TASKS` には置かず、まぜまぜの とき その場で作ります（`makeClockTask`）。
けいさん2問のあとに とけい1問（`CLOCK_EVERY`）。「よむ」（ドラムロール）と「あわせる」（はり）が はんぶんずつ。

| レベル | 時こく |
|---|---|
| 1 ちょうど | 3:00 |
| 2 はん | 7:30（ちょうども すこし） |
| 3 5ふんきざみ | 4:15（ちょうど・はん いがい） |
| 4 1ぷんきざみ | 2:48（:56〜:04 の さかいめを 3わり） |
| 5 ごご | 15:30（13〜23時の ちょうど・はん・5ふん） |
| 6 ごごの 1ぷん | 14:37 |

- 出すレベル：いまの レベル7わり・おさらい3わり。直近10問で6問 あたっていたら つぎの レベルを2わり まぜる
- いまの レベルの おだいを 直近10問で8問、1かいめで あてたら レベルアップ（下がりは しない）
- とけいは ステージの記録に のこさない。レベルと 直近の正解だけ 人ごとに のこす
- よむ も あわせる も「これ！」で こたえる（あわせるは はりを なんかい うごかしても よい）。1かいめの「これ！」だけ 正解として数える
- ヒント・みちしるべは 出さない（ビギナーでも）

60番より うしろの ならびを かえたときは、`TASK_VER` を1つ上げます（読みこむときに 60番より うしろの 古い記録を けす）。
